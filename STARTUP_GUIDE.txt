================================================================================
                      EDUGENIUS AI - TERMINAL STARTUP GUIDE
                      100% Offline & Free NCERT Tutor Platform
================================================================================

All Google AI Studio API keys and paid Gemini API callings have been removed.
This project works completely offline without any internet connection or API keys.

--------------------------------------------------------------------------------
PREREQUISITES:
--------------------------------------------------------------------------------
- Node.js (v18.0.0 or higher)
- Terminal (PowerShell / Command Prompt / Bash)

--------------------------------------------------------------------------------
FIRST TIME SETUP:
--------------------------------------------------------------------------------
Open terminal and navigate to project folder:
    cd remix-edugenius-ai
    npm install

--------------------------------------------------------------------------------
OPTION 1: START IN A SINGLE TERMINAL (RECOMMENDED)
--------------------------------------------------------------------------------
Starts both Backend API and Frontend UI in one unified process:

    cd remix-edugenius-ai
    npm run dev

Once started, open your web browser at:
    http://localhost:3000

--------------------------------------------------------------------------------
OPTION 2: START FRONTEND AND BACKEND IN SEPARATE TERMINALS
--------------------------------------------------------------------------------
TERMINAL 1 (Backend API Server):
    cd remix-edugenius-ai
    npm run dev:backend

    -> Runs on http://localhost:3000
    -> Health check: http://localhost:3000/api/health

TERMINAL 2 (Frontend Client):
    cd remix-edugenius-ai
    npm run dev:frontend

    -> Runs on http://localhost:5173
    -> Automatically proxies /api requests to http://localhost:3000
    -> Open http://localhost:5173 in browser

--------------------------------------------------------------------------------
OPTION 3: PRODUCTION BUILD & START
--------------------------------------------------------------------------------
1. Build the frontend:
    npm run build

2. Start the production server:
    npm start

    -> Runs on http://localhost:3000

--------------------------------------------------------------------------------
ALL AVAILABLE COMMANDS:
--------------------------------------------------------------------------------
npm run dev           -> Combined full-stack dev server (port 3000)
npm run dev:backend   -> Express backend API server (port 3000)
npm run dev:frontend  -> Vite frontend client (port 5173)
npm run build         -> Production build to /dist folder
npm start             -> Production server
npm run lint          -> TypeScript type-check validation

--------------------------------------------------------------------------------
OPTIONAL: LOCAL LLM INTEGRATION (OLLAMA)
--------------------------------------------------------------------------------
To use a local LLM (100% free & offline):
1. Start Ollama:
    ollama run llama3
2. EDUGENIUS automatically detects http://localhost:11434 and uses it.
If Ollama is not running, the built-in NCERT engine handles everything offline!
